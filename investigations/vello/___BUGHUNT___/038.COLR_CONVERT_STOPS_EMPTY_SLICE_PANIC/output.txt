=== Root-cause instrumentation: temporary eprintln! added to ColrPainter::fill in the working
=== tree (glifo/src/colr.rs), reverted afterwards, comparing the ORIGINAL font to the PATCHED
=== (zero-stop ColorLine) font for the exact same glyph (glyph 8):

Note the second run prints NO "DEBUG fill ..." line at all: for the malformed font,
`ColorPainter::fill` (and therefore `glifo::colr::ColrPainter::convert_stops`) is never called for
glyph 8 - skrifa's own paint traversal (skrifa-0.44.0/src/color/traversal.rs,
`traverse_with_callbacks`, the `ResolvedPaint::LinearGradient` arm) resolves the ColorLine's 0
stops into an empty `resolved_stops` vector, matches `(None, _) | (_, None) => {}` on
`(resolved_stops.first(), resolved_stops.last())`, and returns `Ok(())` without ever invoking
`painter.fill(..)`. The identical guard exists for `ResolvedPaint::RadialGradient`, and an explicit
`if resolved_stops.is_empty() { return Ok(()); }` exists for `ResolvedPaint::SweepGradient`.
`glifo::colr::ColrPainter::fill` is the only caller of `convert_stops` in the whole codebase, and
`ColorPainter::fill` is only ever invoked by skrifa's own traversal - so `convert_stops` cannot
receive an empty slice through any real rendering path with this skrifa version.

=== How the malformed font was made (see tools/font_patch/) ===

$ font_patch examples/assets/colr_test_glyphs/test_glyphs-glyf_colr_1.ttf patched.ttf
glyph_id=8 colorline_abs_offset=21078
original numStops=2
wrote patched font with numStops=0 for glyph 8 to patched.ttf

font_patch parses the real test_glyphs-glyf_colr_1.ttf COLRv1 table with read-fonts (via skrifa),
walks the BaseGlyphList/LayerList paint graph to find the ColorLine used by glyph 8's
PaintLinearGradient, and overwrites only that ColorLine's 2-byte `numStops` field with 0 in an
otherwise byte-identical copy of the font (no other offsets/lengths change).
