`texSubImage2D` operation `upload_rgba32ui_rows` performs did NOT throw a JS exception

only converts an actual thrown JS exception into `Err(JsValue)`) would see this call return `Ok(())`
even though the context is lost. `.unwrap()` never observes an `Err` here.
