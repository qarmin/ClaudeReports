| 2026-09-11 | **GDScript has no validated/fast-path getter for reading a NATIVE (C++) class's own property (e.g. `Node2D.position`, `.rotation`, `.visible`, `.modulate`) via an implicit/bare `self` reference - every such read goes through the fully generic, StringName-hash-based `OPCODE_GET_NAMED` -> `Object::get_native()` dispatch, even when the script's exact native base class is statically known at compile time.** Root-caused via `gdscript_byte_codegen.cpp:867` `write_get_named()`: it only emits the fast `OPCODE_GET_NAMED_VALIDATED` opcode (via `Variant::get_member_validated_getter()`) when `HAS_BUILTIN_TYPE(p_source)` - i.e. when the base being indexed is itself a builtin Variant type (Vector2/Vector3/Rect2/...), which is why `some_vector.x` IS fast once `some_vector` is already a temporary.
