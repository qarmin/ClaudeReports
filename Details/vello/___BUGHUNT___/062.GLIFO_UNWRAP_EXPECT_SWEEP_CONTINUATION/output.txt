   does not even exist in a release build. This bug is debug-build-only by construction, not
   because the underlying defect only manifests under debug-assertions checked arithmetic -
   it is a plain out-of-bounds slice index, which panics identically in debug and release; it
   simply cannot be *reached* in release because the whole diagnostics API compiles away.
