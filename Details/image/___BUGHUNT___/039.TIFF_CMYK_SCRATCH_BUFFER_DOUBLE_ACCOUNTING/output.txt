===== Separate empirical threshold sweep (examples/tmp_tiff_cmyk_probe.rs, run in-tree, not part of repro/) =====
Same 1000x1000 CMYK8 source. Shows the exact boundary shifting from "below the true combined
requirement" (before the fix) to "at or above it" (after the fix).

BEFORE (unfixed):
  max_alloc=4300000  ->  Err("Memory limit exceeded")
  max_alloc=5500000  ->  Ok(..)   <- reproduces: 5500000 < 7000000 (rgb 3000000 + cmyk 4000000)
  max_alloc=7000000  ->  Ok(..)   <- reproduces: 7000000 is not < 7000000, but still only just
                                       covers the sum with zero margin for TIFF's own additional
                                       IFD/tag intermediate-buffer needs, i.e. still unsafe
  max_alloc=10000000 ->  Ok(..)

AFTER (patched):
  max_alloc=4300000  ->  Err("Memory limit exceeded")
  max_alloc=5500000  ->  Err("Memory limit exceeded")
  max_alloc=7000000  ->  Err("Memory limit exceeded")
  max_alloc=8000000  ->  Ok(..)   <- only succeeds once max_alloc comfortably covers rgb+cmyk
  max_alloc=10000000 ->  Ok(..)
