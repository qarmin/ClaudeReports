=================== NOTE ON CLASS 1's UNCHANGED VISIBLE OUTPUT ===================
Class 1's printed BezPath is intentionally identical before and after the patch - see RESULT.md's
"The fix" section for why: the patch makes the zero/negative-period fallback an explicit,
documented branch instead of an accidental consequence of `x.rem_euclid(0.0)` == NaN, but for
`period == 0.0` specifically the resulting visible path (a full, undashed passthrough) does not
change, since NaN-vs-explicit-INFINITY both make every `dash_remaining < seg_remaining` comparison
in DashIterator::step() evaluate false. Class 2 (period < 0.0) is where the patch's effect is
visibly dramatic: an unconditional hang becomes a normal, instant return.
